# Investment-Behavior-Analysis-Dashboard-Power-BI
Interactive Power BI Dashboard analyzing investment behavior, preferences, savings objectives, and investor insights using data visualization and business intelligence techniques.


## Project Overview

This project was developed during the Cognifyz Technologies Power BI Internship Program.

The objective was to analyze investor behavior, investment preferences, savings objectives, investment duration, monitoring frequency, reasons for investment, and sources of investment information using Power BI.

## Tools Used

* Power BI
* Power Query
* DAX
* Data Visualization

## Project Tasks

### Task 1: Data Exploration and Summary

* Data Import
* Data Type Analysis
* Average Age Calculation
* Investment Preference Summary

### Task 2: Gender-Based Analysis

* Investment Preference Comparison
* Gender-Based Trends

### Task 3: Objective Analysis

* Savings Objectives vs Investment Choices
* Correlation Analysis

### Task 4: Investment Duration and Frequency

* Duration Distribution
* Monitoring Frequency Analysis

### Task 5: Reasons for Investment

* Better Returns Analysis
* Tax Benefit Analysis
* Wealth Creation Trends

### Task 6: Source of Information Analysis

* Internet Usage
* Newspaper Usage
* Financial Advisor Influence

### Task 7: Interactive Dashboard

* KPI Cards
* Slicers
* Navigation Buttons
* Interactive Charts

## Key Insights

* Mutual Funds emerged as one of the most preferred investment avenues.
* Capital Appreciation was a major savings objective.
* Internet was a leading source of investment information.
* Investment preferences varied across demographic groups.
